# Icone RAL

Icone PNG utilizzate dal sito: 16 e 32 px per le schede del browser, 180 px per la schermata Home Apple, 192 e 512 px per la PWA e le anteprime dei link. La versione 192 px è usata anche nell'intestazione.

Il progetto Pixelmator e l'immagine sorgente rimangono nella cartella locale Icone. I file PNG originali preparati dall'autore non vengono rigenerati.
